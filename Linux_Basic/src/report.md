## Part 3. Настройка сети ОС

- С помощью команды `hostnamectl set-hostname` задаём название машины **user-1**.

![Part_3.1.png](images/Part_3.1.png)

- Устанавливаем необходимую временную зону, с помощью команды `timedatectl set-timezone`.

![Part_3.2.png](images/Part_3.2.png)

- С помощью команды `ip a` выводим названия сетевых интерфейсов.
  - `lo` — это виртуальный сетевой интерфейс "обратной связи" (loopback), который позволяет компьютеру взаимодействовать с самим собой. Он всегда имеет IP-адрес `127.0.0.1` и доменное имя `localhost`. Этот интерфейс необходим для запуска сетевых приложений локально, например, для тестирования ПО или работы серверных служб, когда клиент и сервер находятся на одном компьютере.
  - **DHCP** — это аббревиатура от **Dynamic Host Configuration Protocol**, что переводится на русский язык как **протокол динамической настройки хостов**. Это сетевой протокол, который используется для автоматического назначения сетевых параметров (таких как IP-адрес, маска подсети, шлюз по умолчанию и адреса DNS-серверов) устройствам в сети. В данном случае внутренний IP-адрес **10.0.2.15**, который является шлюзом по умолчанию.

![Part_3.3.png](images/Part_3.3.png)

- Чтобы узнать внешний (публичный) IP-адрес в Linux через терминал, необходимо отправить запрос на специальный сторонний веб-сервис, который отобразит ваш IP-адрес с точки зрения Интернета. Для этого можно использовать утилиту `curl`:
  - `curl ifconfig.me`
  - `curl icanhazip.com`

- Внутренний IP-адрес шлюза (он же IP-адрес по умолчанию, GW). Внутренний IP-адрес шлюза — это адрес маршрутизатора в вашей локальной сети. Он используется вашим устройством для отправки трафика за пределы локальной сети. В выводе команды `ip route | grep default` видна строка, начинающаяся со слова `default`. ## Part 5. Использование команды **sudo**

- **sudo** — это команда в Linux и Unix-подобных системах, которая позволяет выполнять другие команды с правами суперпользователя (root). Даёт временные права root только для выполнения конкретной команды, после чего вы снова становитесь обычным пользователем.

- Чтобы поменять hostname ОС от имени пользователя, созданного в пункте 2, необходимо с помощью команды `sudo usermod -a -G sudo rus` добавить нового пользователя `rus` в группу `sudo`, тем самым дав ему необходимые права на использование sudo. Далее с помощью команды `id` проверяем, что новый пользователь действительно добавлен в группу sudo. Следующим шагом мы логинимся под новым пользователем `rus`, и с помощью команды `sudo hostnamectl set-hostname` задаём новое имя для этой машины. Проверяем актуальный hostname ОС с помощью команды `hostnamectl`.

## Part 8. Установка и базовая настройка сервиса **SSHD**

- Устанавливаем ssh-сервер с помощью команды `sudo apt install openssh-server`.
- Добавляем ssh в автозагрузку с помощью команды `sudo systemctl enable ssh`.
- Запускаем ssh-сервер командой `sudo systemctl start ssh` и проверяем статус `systemctl status ssh`.

![8.1.png](images/8.1.png)

- Меняем порт в конфигурационном файле ssh-сервера `/etc/ssh/sshd_config`, ищем строку `Port 22`. Если строка начинается с символа `#`, его нужно удалить и заменить порт `22` на порт `2022`.
- Проверяем изменения с помощью команды `sudo netstat -tulpan | grep ssh`.

![8.2.png](images/8.2.png)

- Для нахождения информации о процессе `sshd` используем команду `ps -fL -C sshd`, которая показывает состояние процессов. Флаг `-f` выводит максимум доступных данных, флаг `-L` отображает потоки процессов в колонках LWP (легковесный процесс) и NLWP (число легковесных процессов), флаг `-C` выбирает процессы по имени команды.

![8.3.png](images/8.3.png)

- `netstat` показывает содержимое различных структур данных, связанных с сетью, в различных форматах в зависимости от указанных опций. Флаг `-tan` выводит все активные подключения TCP и прослушиваемые компьютером порты TCP и UDP, а также показывает сетевые адреса как числа (обычно `netstat` показывает адреса как символы). Эту опцию можно использовать с любым форматом показа.
  - `State: Listen` — ожидает входящих соединений.
  - `Proto` — протокол, используемый сокетом.
  - `Recv-Q` — количество байтов, не скопированных пользовательской программой, подключенной к этому сокету.
  - `Send-Q` — количество неподтвержденных байтов удаленного хоста.
  - `Local address` — локальный адрес (имя локального хоста) и номер порта сокета.
  - `Foreign address` — удаленный адрес (имя удаленного хоста) и номер порта сокета.
  - `0.0.0.0` — это немаршрутизируемый адрес IPv4, который можно использовать в разных целях, в основном, в качестве адреса по умолчанию или адреса-заполнителя.

## Part 9. Установка и использование утилиты **top** и **htop**

- **Uptime** — перезагрузка была сделана 23 мин назад
- Количество авторизованных пользователей — 1 user
- Общая загрузка системы — load average (0.00, 0.10, 0.54)
- Общее количество процессов — 106 total
- Загрузка CPU — это статистика загрузки процессора (3-я строчка):
  - `us` — процент использования ЦП пользовательскими процессами
  - `sy` — процент использования ЦП системными процессами
  - `ni` — процент использования ЦП процессами с приоритетом, повышенным при помощи вызова
  - `id` — процент времени, когда ЦП не используется
  - `wa` — процент использования ЦП процессами, ожидающими завершения операций ввода-вывода
  - `hi` — Hardware IRQ (аппаратные прерывания) — процент использования ЦП обработчиками аппаратных прерываний
  - `si` — Software Interrupts (программные прерывания) — процент использования ЦП обработчиками программных прерываний
  - `st` — Steal Time (заимствованное время) — количество ресурсов ЦП "заимствованных" у виртуальной машины гипервизором для других задач
- Загрузка памяти — в 4-й и 5-й строке выводится информация об использовании физической оперативной памяти и раздела подкачки (swap). Значения в порядке следования: общее количество памяти (`total`), количество используемой памяти (`used`), количество свободной памяти (`free`), количество памяти в кэше буферов (`buffers`).
- PID процесса, занимающего больше всего памяти:
  - PID: `1`
  - VIRT: `103956`
  - RES: `12916`
- PID процесса, занимающего больше всего процессорного времени:
